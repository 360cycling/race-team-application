# 360 Cycling — Race Team Applications

Recruitment page for the **360 Cycling** 2027 Junior (JRT) and Under-23 race teams.

- Single self-contained `index.html` (all images embedded) — no build step, no dependencies.
- Applications are composed as an email to `info@360cycling.co.uk` (copied to `josh@360cycling.co.uk`) with the applicant's CV attached; the page stores nothing and has no server.
- Hosted on GitHub Pages.

Open `index.html` in any browser, or visit the live Pages URL.
